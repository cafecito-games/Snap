# Snap (binary distribution)

This branch is auto-generated by the release pipeline. Its
`Package.swift` resolves every product to the prebuilt XCFrameworks
attached to the latest release, so consumers compile no Snap sources.

Usage:

    .package(url: "https://github.com/cafecito-games/Snap", branch: "binary")

For a version-pinned binary dependency, use the matching
`binary-<tag>` tag:

    .package(url: "https://github.com/cafecito-games/Snap", exact: "binary-0.1.0")

The source distribution lives on `main`.
